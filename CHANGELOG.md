# Changelog

## 0.1.0 — Initial release

- Add bounded Gregorian civil-date and leap-year calculations.
- Add seven week-start transformations and natural/fixed month grids.
- Add explicit adjacent-date handling and undated blank-grid primitives.
- Add nominal A4, A5, US Letter, US Legal, and custom paper geometry.
- Add derived 2027 fixtures, a 2026–2027 boundary regression window, and reusable validation functions.
